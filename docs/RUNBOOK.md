# Runbook

1. Install Docker Desktop with WSL2 integration and Git.
2. Copy `.env.example` to `.env`. Values are demo-only. Never expose this Compose stack to the internet.
3. Build realm JSON with `node keycloak/build-realm.mjs`.
4. Run `docker compose up --build`.
5. Open `http://localhost:3000`, Keycloak `http://localhost:8080`, API health `http://localhost:4000/health`, Student Portal `http://localhost:3001`, Library Portal `http://localhost:3002`, LDAP `localhost:1389`.
6. Demo seeded password: `Ganpat@Demo2026!` for all imported users. This is intentionally documented demo data; change it before real use. TOTP users are asked to configure TOTP at first login; no TOTP seed is stored in this repository.
7. If realm import fails, inspect `docker compose logs keycloak`. The JSON format is generated by `keycloak/build-realm.mjs`; do not configure Keycloak manually.
8. To reset all demo data, run `docker compose down -v` then `docker compose up --build`.
9. The SAML endpoint is only a scaffold; do not present it as a verified SAML login.
